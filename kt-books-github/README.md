# Библиотека — React КТ 1, вариант 1

Учебное приложение на JavaScript, React, React Router и Vite. Реализованы все задачи 1–10; ответы на теорию и исправленный `BookPanel` находятся в `answers.md`.

## Запуск

Установите Node.js версии 22.12 или новее (подойдёт 24 LTS). Откройте терминал в папке `kt-books`, где лежит `package.json`, и выполните:

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает Vite, обычно http://127.0.0.1:5173 . Остановить сервер можно сочетанием Ctrl+C. Файл `index.html` двойным щелчком открывать не нужно: приложение запускается через Vite.

## Файлы проекта

- `src/main.jsx` — настройка маршрутов и StrictMode.
- `src/storage.js` — хранилище из задания, его логика сохранена без изменений.
- `src/routes/root.jsx` — меню, добавление, список и заголовок вкладки.
- `src/routes/book.jsx` — страница книги, секундомер, подтверждение удаления.
- `src/routes/delete.jsx` — action удаления и переход на главную.
- `src/routes/error-page.jsx` — вывод ошибок роутера.
- `src/index.css` — простое оформление и классы active/pending.
- `answers.md` — пять ответов на теорию и задача 10.

## Проверка по заданию

1. На `/` видны заголовок «Библиотека», четыре книги и «Выберите книгу из списка».
2. При выборе книги открываются название, автор, год, кнопка удаления и секундомер. Активная ссылка коричневая и жирная, ожидающая загрузки — серая.
3. Добавьте книгу: на время отправки кнопка блокируется и показывает «Добавляем...», затем открывается новая запись, список обновляется, в заголовке вкладки — «Книг: 5». Год сохраняется числом.
4. Нажмите «Удалить»: отказ в диалоге оставляет книгу, подтверждение удаляет её и открывает `/`, количество во вкладке уменьшается.
5. На странице книги секунды растут по одной; при переходе между книгами счёт начинается с нуля, при уходе интервал очищается. StrictMode включён.
6. `/books/abc` показывает «Ой! Not Found» внутри страницы с меню; `/qwerty` показывает ошибку вместо всего приложения.
7. Если удалить все книги, появляется «Книг пока нет», в заголовке вкладки — «Книг: 0»; форму добавления по-прежнему можно использовать.
8. При обновлении страницы записи сохраняются: данные находятся в localStorage этого браузера для текущего адреса.

Чтобы восстановить четыре исходные книги, удалите ключ `kt-books` в localStorage через инструменты разработчика и обновите страницу. Пустой массив `[]` не восстанавливает исходные книги: это корректное пустое состояние.

## Сборка и сдача

```sh
npm run build
npm run preview
```

`npm run build` создаёт папку `dist`. Для сдачи передайте исходную папку проекта вместе с `answers.md` и `package-lock.json`, без `node_modules`. В архиве решения зависимости и папка сборки не включены. Интернет нужен для первоначальной установки пакетов; само приложение использует только localStorage и не требует сервера данных.
