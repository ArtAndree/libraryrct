# Ответы — КТ 1, вариант 1 «Книги»

## Часть 0. Теория

### 1. Когда запускается useEffect?

Без массива зависимостей эффект запускается после каждого завершённого рендера; с `[]` — после первого монтирования; с `[x]` — после монтирования и при изменении `x` (сравнение через `Object.is`). В режиме разработки `StrictMode` дополнительно выполняет проверочный цикл запуска и очистки при монтировании.

### 2. Для чего нужна очистка?

Функция очистки освобождает ресурсы перед следующим запуском эффекта с изменёнными зависимостями и при размонтировании компонента. Она нужна, например, для остановки `setInterval` через `clearInterval` и удаления обработчика, добавленного через `addEventListener`, с помощью `removeEventListener`.

### 3. Чем Link отличается от a?

`Link` выполняет переход внутри приложения средствами React Router без полной перезагрузки документа и сохраняет работу SPA. Обычный `<a href="...">` при стандартном переходе загружает новый документ; он подходит, например, для внешних сайтов.

### 4. Что происходит после action и что он возвращает?

После успешного `action`, вызванного через роутер, React Router автоматически повторно загружает данные активных маршрутов через их `loader`, чтобы интерфейс показывал актуальные записи. `action` должен вернуть результат обработки, например объект с данными, `null` или `Response`; в этой работе возвращается `redirect(...)` для перехода на нужную страницу.

### 5. Зачем преобразовывать FormData?

`FormData` — специальный объект, а не обычный объект с полями, причём значения обычных полей, включая `input type="number"`, приходят строками. Обычный объект получают через `Object.fromEntries(formData)`, а год перед записью преобразуют в число: `Number(values.year)`.

## Часть 3. Задача 10. Ошибки в BookPanel

1. Ранний `return` при `loading` стоит до хуков: при изменении `loading` меняется число вызываемых хуков, поэтому все хуки надо вызывать до условного возврата.
2. `useEffect` вызывается внутри `if (showNote)`: это нарушает постоянный порядок хуков, поэтому условие надо перенести внутрь эффекта.
3. У эффекта заголовка пустой массив зависимостей: заголовок не обновится при изменении книги или заметки, поэтому нужно перечислить используемые изменяемые значения, в том числе флаги условия.
4. Интервал не очищается: после изменения `note` запускается ещё один интервал, а при уходе со страницы старые продолжают работать, поэтому эффект должен возвращать `clearInterval`.

### Исправленный компонент

```jsx
import React, { useEffect, useState } from 'react';

function BookPanel({ book, showNote, loading }) {
  const [note, setNote] = useState('');
  const title = book?.title;

  useEffect(() => {
    if (!loading && showNote && title !== undefined) {
      document.title = `${title}: ${note}`;
    }
  }, [loading, showNote, title, note]);

  useEffect(() => {
    if (loading) return;

    const id = setInterval(() => console.log(note), 1000);
    return () => clearInterval(id);
  }, [loading, note]);

  if (loading) {
    return <p>Загрузка...</p>;
  }

  return <input value={note} onChange={(e) => setNote(e.target.value)} />;
}
```

Все хуки вызываются безусловно. Проверки находятся внутри эффектов, а необязательный доступ `book?.title` позволяет безопасно получить название, даже когда книга ещё загружается. При изменении заметки старый интервал удаляется до создания нового; при размонтировании он также удаляется.

Материалы для проверки: [useEffect](https://react.dev/reference/react/useEffect), [Actions в React Router](https://reactrouter.com/start/data/actions).
